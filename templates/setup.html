Como executar o coletor

Baixe o repositório Nexo Monitor na máquina que ficará ligada na unidade. Instale Python e as dependências. O token aparece uma única vez no cadastro do coletor; gerar outro revoga o anterior.

python -m pip install -r collector/requirements.txt
Windows — PowerShell
$env:NEXO_URL="https://DOMINIO_DA_CENTRAL"
$env:NEXO_TOKEN="TOKEN_DO_SEU_COLETOR"
python collector/agent.py
Linux — terminal
export NEXO_URL="https://DOMINIO_DA_CENTRAL"
export NEXO_TOKEN="TOKEN_DO_SEU_COLETOR"
python collector/agent.py

Substitua os exemplos. Eles não são credenciais reais. A execução manual termina quando o processo é encerrado; a instalação como serviço automático ainda precisa ser configurada. Ping e SNMP exigem executáveis locais adicionais.

Entenda os estados

  • Disponível: a última verificação passou.
  • Indisponível: as falhas atingiram o limite configurado.
  • Sem dados recentes: falta coleta atual ou a falha ainda está sendo confirmada. Não é prova de queda.
  • Pausado: equipamento desativado para coleta.

Uma central instalada não descobre os equipamentos automaticamente. Outras unidades precisam de coletor próprio. CPU, memória, disco e serviços locais pertencem à máquina do coletor.

O que ainda falta

A primeira configuração não certifica a operação real. Ainda precisam de teste: HTTPS, coleta nos equipamentos, envio de WhatsApp/e-mail, restauração de backup e monitor externo.

Funções pendentes incluem descoberta de equipamentos, topologia visual, gestão manual de incidentes, relatórios mensais, tráfego por segundo, dados Wi-Fi detalhados, gravação recente e integrações específicas dos fabricantes.
